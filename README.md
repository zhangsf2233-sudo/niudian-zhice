# 牛店智策

乳品门店拜访决策工作台。独立校园创新大赛参赛原型。

- 网页版：https://zhangsf2233-sudo.github.io/niudian-zhice/
- 手机版：https://zhangsf2233-sudo.github.io/niudian-zhice/mobile.html
- 产品方案 PDF：https://zhangsf2233-sudo.github.io/niudian-zhice/project.pdf

打开即可体验，不需要登录、安装或启动本地服务。网页中内置模拟数据、分析规则、界面样式和产品截图，运行时不依赖外部 CDN、密钥或付费接口。

## 可体验功能

产品介绍、门店优先级与拜访容量调整、三类异常案例、商品行动卡、原始证据、现场检查项与本机回填、JSON/CSV导入和计划/分析导出。

## 演示边界

30家虚拟门店、3个示意商品、56天销量，数据截至2026-10-09。所有经营记录为固定种子合成模拟，不是蒙牛内部数据。数值与排序由浏览器规则计算，未调用实时大模型；本机回填不跨设备共享。没有真实企业试点或销量增益结论。

## 发布方式

GitHub Pages：main 分支根目录。index.html为网页入口，mobile.html为手机入口。两个入口都支持响应式布局。所有发布文件不含服务端密钥、账号凭据或运行记录。
